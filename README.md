# DRESS UP! — 나만의 코디 편집실

## 기능
- 전신 사진과 얼굴 사진 등록
- 옷 사진을 카테고리별 스티커로 추가
- 보드에서 이동, 크기 조절, 회전, 앞/뒤 순서 변경
- 자동 배경 제거(브라우저에서 실행) 후 지우개/복구 브러시로 수정
- 코디를 브라우저에 저장하거나 PNG로 내보내기

## 실행
Node.js 18 이상에서:
```bash
npm start
```
브라우저에서 `http://localhost:3000` 접속.

## 자동 누끼 안내
자동 누끼 기능은 `@imgly/background-removal`을 브라우저에서 동적으로 불러옵니다. 첫 사용 시 라이브러리와 AI 모델 파일을 인터넷에서 내려받으므로 시간이 걸릴 수 있고, 기기 성능과 브라우저 메모리에 따라 iPad에서 느리거나 실패할 수 있습니다. 자동 누끼 과정의 사진 파일은 이 앱 서버로 업로드하지 않고 브라우저 안에서 처리합니다. CDN 및 모델 다운로드에는 인터넷 연결이 필요합니다.

## 저장 및 개인정보
코디 저장은 현재 브라우저의 localStorage를 사용합니다. 브라우저 데이터/사이트 데이터를 지우거나 다른 기기·브라우저를 사용하면 저장한 코디가 사라질 수 있으므로 중요한 코디는 PNG로 내보내세요. 업로드한 사진은 별도 서버에 전송하지 않습니다.

## 라이선스 주의
자동 배경 제거 패키지는 오픈소스 라이선스 조건이 적용됩니다. 개인용 테스트를 넘어 공개·상업 서비스로 배포하기 전에는 해당 패키지와 모델의 최신 라이선스 조건을 확인하세요.
